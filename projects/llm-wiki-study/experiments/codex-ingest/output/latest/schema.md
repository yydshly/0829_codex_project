# Wiki Schema

所有页面使用中文正文、YAML frontmatter、`sources` 数组和必要的 `[[wikilink]]`。

建议页面类型：

- `wiki/cases/`：合成或真实案例，必须明确性质、时间线、影响链与证据边界。
- `wiki/concepts/`：可跨案例复用的概念和区分。
- `wiki/methods/`：可执行的方法、输入、步骤、输出和验收标准。
- `wiki/principles/`：治理原则、适用条件与不适用边界。
- `wiki/sources/`：输入资料摘要与来源性质。

不要把模型推断写成原始资料事实；证据不足时生成 Review 或明确标注未知。
